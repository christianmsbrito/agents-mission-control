# Backfill Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A standalone `bun run backfill` CLI that imports historical agent sessions from on-disk provider data into `~/.mission-control/mc.db` (registry + hour-resolution samples + lifecycle events), then optionally enriches them with batched Haiku (subject/summary/needs-action) — all with nested graceful degradation.

**Architecture:** New `packages/server/src/backfill/` (adapter contract + registry + orchestrator + enrich phase) and `scripts/backfill.ts` (CLI). Each provider is an isolated `BackfillAdapter` that reuses the existing `packages/reporter/src/providers/*` parsers for aggregation and does a small extra walk for sample points. The orchestrator enforces provider→session→field guards. No live-server hot-path changes beyond 4 additive registry columns + `record()` writing them. Reuses `Store`, `sessionKeyOf`, `condenseSamples`, `hourBucket`, `estimateCost`, `resolveCategory`.

**Tech Stack:** Bun, `bun:sqlite`, TypeScript (explicit `.ts` extensions), `@anthropic-ai/sdk`, `*.test.ts` colocated, `:memory:`/temp-file DB + mocked Anthropic client in tests.

**Companion design:** `docs/plans/2026-06-18-backfill-design.md` (read for rationale, per-provider mapping, resume corrections).

**Conventions (from CLAUDE.md):** explicit `.ts` extensions; pure-function-first tests; side-effects at edges; `enrich()`/store calls must never throw to the caller (graceful degradation); commit after each task; run `bun test` before each commit.

describe("runBackfill core", () => {

## Risks / open verifications (resolve during, don't guess)

- **Sample synthesis needs raw-line walks** — the existing parsers only return aggregates; each sample-capable adapter (claude/codex/openclaw) needs its own small timestamped-usage extractor feeding `condenseSamples`. Don't try to bend `parseClaudeTranscript` into emitting a series.
- **opencode resume flag** unverified → leave `resumeId` undefined (disabled button), don't guess `--session`.
- **codex model name** absent in rollouts → infer coarse ("gpt-5") or leave model partial; note it.
- **hermes timestamps are epoch seconds** (×1000) and **cwd is null**; category comes from `source`, not the cwd resolver.
- **Anthropic structured output drift** — validate each returned item; id-key the mapping; cap batch size + per-tail length against the context window.
- **`--dry-run` path** must not write — thread it into the orchestrator, not just the CLI.
